Function-on-function regression

1 A locally sparse coefficient surface

A functional response depends on a functional predictor through a surface:

\[ y_i(s)=\int_0^1 x_i(t)\psi(t,s)\,\mathrm dt+\varepsilon_i(s), \qquad \psi(t,s)=\boldsymbol\varphi(t)^\top\boldsymbol\Psi\boldsymbol\theta(s). \]

The \(M\times L\) coefficient matrix connects predictor-domain and response-domain basis functions. Locally sparse function-on-function regression uses an overlapping-group penalty adapted to this tensor-product basis (Bernardi, Canale, and Stefanucci 2023). The example uses \(M=8\), \(L=5\) and a surface supported on only part of the domain.

We retain the predictor curves and quadrature convention from the previous chapter. In this version of f2fSP(), both basis grids are constructed from the number of columns of mX; use the same grid length for predictor and response in this workflow.

set.seed(301)
Theta <- splines::bs(t,df=5,intercept=TRUE)
Psi_true <- matrix(0,8,5)
Psi_true[3:4,2:3] <- 2
surface_true <- H %*% Psi_true %*% t(Theta)
Y_curves <- X_quad %*% surface_true +
  matrix(rnorm(n_fun*length(t),sd=.04),n_fun,length(t))

2 Estimate the surface and choose the tuning parameter

surface_fit <- f2fSP(mY=Y_curves,mX=X_quad,M=8,L=5,
                     nlambda=20,lambda.min.ratio=.001,
                     standardize.data=FALSE,control=control)
check_path(surface_fit)
set.seed(302)
surface_cv <- f2fSP_cv(mY=Y_curves,mX=X_quad,M=8,L=5,
                       lambda=surface_fit$lambda,cv.fold=5,
                       standardize.data=FALSE,control=control)
i_surface <- which.min(abs(surface_fit$lambda-surface_cv$lambda.min))
Psi_est <- surface_fit$sp.coef.path[i_surface,,]
surface_est <- H %*% Psi_est %*% t(Theta)
stopifnot(max(abs(surface_est-surface_fit$sp.fun.path[i_surface,,]))<1e-8)

We reconstruct the selected surface explicitly from sp.coef.path, whose first dimension indexes the tuning parameter. This also makes the predictor and response axes unambiguous.

surface_plot <- rbind(
  transform(expand.grid(t=t,s=t),value=as.vector(surface_true),panel="Truth"),
  transform(expand.grid(t=t,s=t),value=as.vector(surface_est),panel="CV estimate"))
ggplot(surface_plot,aes(t,s,fill=value)) + geom_raster() + coord_equal() +
  facet_wrap(~panel) + scale_fill_gradient2(low="#2166ac",mid="white",high="#b2182b") +
  labs(x="Predictor domain t",y="Response domain s",fill=expression(psi(t,s)))

True and estimated coefficient surfaces on a common colour scale. Horizontal coordinates index the predictor domain; vertical coordinates index the response domain.

3 Examine the path and predict curves

surface_path_matrix <- matrix(surface_fit$sp.coef.path,
                               nrow=length(surface_fit$lambda))
ggplot(path_data(surface_path_matrix,surface_fit$lambda),
       aes(lambda,coefficient,group=term)) + geom_line(colour="#9e1b32",alpha=.6) +
  scale_x_log10() + labs(x=expression(lambda),y="Tensor-product coefficient")

Tensor-product coefficient paths; the first array dimension indexes the regularization parameter. 

set.seed(303)
Ynew <- Xnew_quad %*% surface_true +
  matrix(rnorm(nrow(Xnew_quad)*length(t),sd=.04),nrow(Xnew_quad),length(t))
Ypred <- Xnew_quad %*% surface_est
subject <- 1
curve_prediction <- data.frame(s=rep(t,2),value=c(Ynew[subject,],Ypred[subject,]),
                                curve=rep(c("Observed","Predicted"),each=length(t)))
mean((Ynew-Ypred)^2)
## [1] 0.001580285
ggplot(curve_prediction,aes(s,value,colour=curve)) + geom_line(linewidth=.8) +
  labs(x="Response domain",y="Response",colour=NULL)

Observed and predicted response for a held-out subject.

Prediction error and recovery of the coefficient surface answer different questions. A correlated functional design can predict well without uniquely recovering every feature of a surface. The test subjects above are separate from the subjects used for fitting and CV. f2fSP() does not return a dof component in the supplied version; this guide does not substitute a count of nonzero basis coefficients for a functional degrees-of-freedom formula.
